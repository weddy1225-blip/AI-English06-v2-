# 🎧 音軌整理師 (Audio Track Organizer)

這是一個專為國小學生設計的** AI 互動式聽力與語法練習遊戲。學生將化身為專業的「音軌修復師」，協助粗心的實習生將亂跳的單字重新排列，修復損壞的音軌。

### 🎯 教學目標
* **語法修復**：透過「重組題」練習正確的英語句子結構（S + V + O）。
* **聽力辨析**：透過「挖空辨音題」區分容易混淆的最小對立體單字（例如：`sheep` vs `ship`）。
* **沉浸式學習**：結合Web Speech API，讓學生在操作過程中反覆聆聽正確發音，強化音形意連結。

### 🤖 專業修復邏輯
本遊戲內建嚴謹的偵測與防呆機制：
1. **防呆置換機制**：在挖空題中，空格區限制一次僅能放入一個單字，若放入新單字，舊單字會自動彈回備選區，避免邏輯錯誤。
2. **即時回饋系統**：提交後立即顯示「整理完成」或「整理失敗」的視覺回饋。
3. **任務報告書**：遊戲結束後提供完整清單，對比學生的「修復紀錄」與「正確音軌」，方便訂正與檢討。

### 🛠 使用技術
* **HTML5 / CSS3**：響應式介面設計，支援平板與電腦操作。
* **Vanilla JavaScript**：輕量化高效能邏輯運算。
* **Web Speech API (TTS)**：美式英語語音合成，提供流暢的聽力來源。
* **Drag and Drop API**：直覺化拖拉操作，訓練手眼協調。
